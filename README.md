# Java Chat Application - Part 1

This is an individual Java-based project that utilizes Object-Oriented Programming (OOP) principles to build a basic GUI-driven chat application. It includes a `Login` class that validates user credentials and simulates a login and registration system.

## 🛠️ Tools & Technologies Used

- **NetBeans IDE**
- **Java Swing GUI**
- **JUnit Testing**
- **Git & GitHub**
- **ChatGPT**

## 💡 Project Description

The application allows users to:

- **Register**: Users can create an account by entering their details.
- **Login**: Users can sign in using their registered credentials.
- **System Responses**: The application provides responses based on user input for both login and registration actions.

We applied the **OOP approach** throughout the project, focusing on concepts like encapsulation, inheritance. Additionally, **JUnit tests** were used to validate the logic of key methods, ensuring the application behaves as expected, chatGPT was used to help to generate **reg expression** for cell phone number validation .

## ✅ Features

- Graphical User Interface (GUI) using **Java Swing**
- Basic **form validation** for login and registration
- **Error handling** for incorrect inputs
- **Unit testing** using **JUnit** to verify logic correctness
- Version control with **Git and GitHub**
